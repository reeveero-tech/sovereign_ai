## 4) التنفيذ

- `--range BASE HEAD`: فحص كل التزام بنفسه (اسم+بريد المؤلف يُتجاهلان —
  دمجي أو بشري سواء).
- `docs/ROADMAP_ACTIVE.txt`: مؤشر الخارطة النشطة — القبول مشروط بما فيه حصرًا.
- CODE_PREFIXES: أضيفت `scripts/` و`.githooks/`.
- الحذف (حالة D) لا يُحتسب تحديث وثائق.
- CI: بوابة الدفع → `--range "${{ github.event.before }}" HEAD` مع رجوع موثق
  لفحص الرأس عند غياب قاعدة دفع صالحة؛ بوابة PR → `--range BASE HEAD`
  (fetch-depth: 0 قائم).
