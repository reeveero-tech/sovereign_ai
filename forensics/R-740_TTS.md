**التاريخ:** 2026-10-24 — بأمر المالك («ابدأ» — تابع الخارطة، المرشح ٢.٤).
**القاعدة:** RED→GREEN حقيقي مُشاهد (المادة ٢) + دفعة ذرية واحدة (المادة ٤).

## ١) ما الذي بُني (ومعيار الإغلاق)

معيار البند في الخارطة: «اختبار: نص → مقطع صوتي + زر تحكم». النصفان
معًا في هذه الجولة:

### أ) الخادم — نص → مقطع صوتي
- **`backend/tts_client.py`** — عقد OpenAI speech القياسي:
  POST `{base}/audio/speech` بجسد `{model, input, voice?}` والاستجابة
  بايتات صوت ثنائية. يغطي السحابي (مثال Groq: `playai-tts`) والمحلي
  المتوافق (piper/kokoro بغلاف OpenAI) بعقد واحد.
- **`POST /tts`** (JSON `{text}`) → `Response` بصوت ثنائي (audio/*).
  صدق كامل: معطل → **503** بالسبب؛ فشل الخدمة → **502**؛ نص فارغ →
  **400**؛ تجاوز حد الطول → **413**؛ تجاوز المعدل → **429**. لا صوت
  مختلق، والاستجابة غير الصوتية تُرفض (لا إرجاع جسد خطأ كصوت).
- **`GET /tts/status`** — الحالة بلا أي سر (عنوان معقّم).
- **حراس:** حد طول 2000 حرف، حد معدل بحد `/chat` نفسه لكل IP، معطل
  افتراضيًا، fail-closed، لا مفتاح ولا نص في السجلات.

### ب) الواجهة — زر التحكم
- **زر `btn-tts-toggle`** في صف إدخال المحادثة (بجانب «إرسال») — تصنيف
  control في LIVE_BINDINGS (حارس R-730 يفحص التغطية آليًا).
- **`frontend/js/modules/voice-output.js`** — تبديل يبقى بين الجلسات
  (localStorage)، ونطق رد الذكاء عبر `POST /tts` وتشغيل الصوت، وفشل
  صادق: 503/502 يُعلنان بإشعار (لا صمت كاذب ولا صوت مختلق).
- **خطاف المحادثة** — `chat-runtime.js` يستدعي `SOVEREIGN_VOICE.speak`
  عند وصول الرد (لا وحدة مجهولة تكتب في الواجهة).
- مجرّدة في `frontend/INVENTORY.md` (وحدة حقيقية تستهلك API — 8/77).

## ٢) الإعدادات (بيد المالك — أسرار المنصة، لا المحادثة)

```
TTS_ENABLED=true            # التفعيل — قرار تشغيلي
TTS_MODEL=playai-tts        # (Groq) أو نموذج خادم محلي متوافق
TTS_BASE_URL=http://127.0.0.1:8880/v1   # محلي افتراضيًا
TTS_API_KEY=<سر الخدمة إن كانت سحابية>
TTS_VOICE=                  # اختياري — None للخادم المحلي
```

> نمط R-736..R-739: سير النشر لا يمرر هذه المتغيرات — تُضبط مباشرة
> `fly secrets set -a sovereign-ai-k20elq ...` ثم أمر نشر (المادة ١٠).
> التحقق الحي بعده: `/tts/status` ثم نص عبر `/tts` + الزر في الواجهة.
