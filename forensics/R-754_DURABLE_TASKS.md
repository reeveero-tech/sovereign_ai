# R-754 — مهام طويلة الأمد دائمة (ROADMAP_V5 ٣.١ + ٣.٢ + ٣.٣)

> بأمر المالك 2026-10-25: «أسلمك المشروع ابدء ولا تتوقف إلى بعد تحقيق الهدف».

## ما بُني
- `backend/durable_tasks.py`:
  - `TaskStore`: ملف JSON لكل مهمة (`id/goal/planner/status/steps/intents/result/runs`)، كتابة ذرية (ملف مؤقت + fsync + `os.replace` + fsync للمجلد)، معرفات مُتحقق منها (لا مسارات).
  - `DurableRunner.create/run/progress`: `run` يستأنف تلقائيًا؛ المهمة المنتهية لا تُعاد.
- `backend/agent_loop.py`: `run(goal, run_id, initial_steps, before_invoke, after_step)` — النية تُكتب قبل الاستدعاء ونقطة التفتيش بعده؛ فشل أيهما يوقف الحلقة (`checkpoint_failed`). أثر `agent_run` بمرحلة `resume` و`resumed_from`.
- أدوات: `tasks.start` (عقل حي)، `tasks.resume`، `tasks.progress`.

## منطق منع التكرار (٣.٢)
| حالة النية المعلقة عند الاستئناف | السلوك |
|---|---|
| أداة داخلية | تُعاد (لا أثر خارجي) |
| أداة خارجية تعلن `idempotency_key` | تُعاد بنفس المفتاح `task_id:index` — الطرف يزيل التكرار (بالضبط مرة) |
| أداة خارجية بلا مفتاح | لا تُعاد أبدًا → `needs_owner_review` (مرة على الأكثر) |
