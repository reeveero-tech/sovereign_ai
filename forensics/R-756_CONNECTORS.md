# R-756 — عقد الموصل المعزول (ROADMAP_V5 ٤.١)

> بأمر المالك 2026-10-25: «أسلمك المشروع ابدء ولا تتوقف إلى بعد تحقيق الهدف».

## ما بُني
- `backend/connectors.py`:
  - `ConnectorSpec` (اسم/أفعال/مدخلات/وصف) و`ConnectorHub` (تسجيل، منح، سحب، تجديد، استدعاء، حالة).
  - **مصادقة مملوكة:** السر في خزينة R-752 باسم `connector.<اسم>` ونطاق `connector:<اسم>` — لا سر في الأثر أو المخرجات.
  - **أذونات لكل فعل:** منحة المالك تحدد الأفعال؛ لا منحة = رفض قبل أي طلب.
  - **انتهاء صلاحية/تجديد:** `ttl_s` ثم رفض آمن حتى `renew`.
  - **سحب فوري:** حالة المنح تُقرأ من القرص (`data/connectors/`) عند كل استدعاء — سحب من عملية أخرى يقطع الاستدعاء التالي.
  - **عزل الفشل:** قاطع دائرة لكل موصل (فتح بعد فشل متتالٍ، تهدئة، نصف مفتوح).
  - **أثر:** نية `connector_call` قبل التنفيذ (فشلها = لا تنفيذ) ونتيجة بعده.
  - أول موصل: `webhook` — `notify` (POST + Bearer + Idempotency-Key) و`health` (GET)، حارس SSRF.
- `backend/app.py`: `/connectors/status`، `POST /connectors/grant` و`/connectors/revoke` (مفتاح API للمالك)، أدوات `connectors.status` و`connector.<اسم>.<فعل>`.
- `backend/durable_tasks.py`: أفعال الموصلات أدوات خارجية — لا تُعاد عند الاستئناف إلا بمفتاح idempotency (R-754 ٣.٢).
- الجرد: قدرة `connectors` (مرتكز `connectors.status`، علم `vault`، تتطلب التوقيع).
