# R-753 — حلقة الوكيل العامة (ROADMAP_V5 ٢.١ + ٢.٢ + ٢.٣)

> بأمر المالك 2026-10-25: «أسلمك المشروع ابدء ولا تتوقف إلى بعد تحقيق الهدف».

## ما بُني — `backend/agent_loop.py`
- `AgentLoop.run(goal)`: أثر `agent_run` (start) ← حلقة: فحص الإلغاء والميزانيات ← خطوة من المخطط ← تحقق من صلاحيتها (أداة مسجلة ومسموحة، لا `agent.run`، نوع تحقق معروف) ← `registry.invoke` (أثر `tool_invoked`) ← `verify()` ← استمرار أو توقف ← أثر `agent_run` (finish/cancelled/stopped).
- حالات النهاية: completed / tool_failed / verification_failed / budget_exhausted / cancelled / invalid_step / planner_failed / ledger_blocked. الجواب يُعاد عند completed فقط.
- المخططان: `BrainPlanner` (ollama_client.chat، JSON صارم؛ رد غير صالح أو عقل غائب → planner_failed) و`ScriptedPlanner` (بديل اختبار حتمي — يشتق موضعه من السجل فيصلح للاستئناف في §٣).
- أداة `agent.run` (هدف + سقف خطوات ≤32) في السجل؛ `EventType.AGENT_RUN`؛ الجرد: علم `brain` + توقيع.
