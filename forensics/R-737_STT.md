# R-737 — البند ٢.٣ (أذنان): تحويل الكلام لنص عبر مدخل /stt

**التاريخ:** 2026-10-23 — بأمر المالك («ابدأ» — تابع الخارطة، المرشح ٢.٣).
**القاعدة:** RED→GREEN حقيقي مُشاهد (المادة ٢) + دفعة ذرية واحدة (المادة ٤).

## ١) ما الذي بُني (ومعيار الإغلاق)

معيار البند في الخارطة: «اختبار: مقطع صوتي → نص». المنفذ:

- **`backend/stt_client.py`** — عميل خدمة تحويل كلام متوافق مع OpenAI
  (البروتوكول القياسي: `POST {base}/audio/transcriptions` بطلب multipart —
  الاستجابة `{text}`). بروتوكول واحد يغطي المصدرين في نص الخارطة
  («Whisper محلي أو خدمة»):
  - خادم whisper.cpp محلي (نقطته متوافقة مع OpenAI — العنوان الافتراضي
    `http://127.0.0.1:8080/v1`؛ الخادم يقرر النموذج فلا `STT_MODEL` مطلوب).
  - خدمة سحابية (مثال Groq: `whisper-large-v3` على الأساس نفسه).
- **`backend/app.py`** — نقطتان:
  - `POST /stt`: ملف صوتي (multipart) → `{"text": ...}`. حراسة بصدق:
    معطل → **503** بالسبب؛ فشل الخدمة → **502**؛ حجم زائد → **413**؛
    نوع غير صوتي → **415**؛ تجاوز المعدل → **429**. لا نص مختلق أبدًا.
  - `GET /stt/status`: الحالة بلا أي سر (العنوان معقّم — نمط /brain/status).
- **حدود صارمة:** قراءة بحد + 1 بايت (لا قراءة اعتباطية في الذاكرة —
  افتراضي 25MiB)، قائمة أنواع صوتية مسموحة فقط، وحد معدل بحد `/chat`
  نفسه لكل IP مباشر (الرفع باهظ — لا باب مفتوح).
- **مبادئ قائمة محفوظة:** معطل افتراضيًا (لا اتصال ضمني)، fail-closed
  (None لا استثناء)، لا مفتاح ولا محتوى صوتي ولا نص مستخرج في السجلات
  (نوع الخطأ فقط).

## ٢) الإعدادات (كلها بيد المالك — أسرار المنصة، لا المحادثة)

```
STT_ENABLED=true                                   # التفعيل — قرار تشغيلي
STT_BASE_URL=http://127.0.0.1:8080/v1             # محلي (whisper.cpp)
# أو السحابي: https://api.groq.com/openai/v1
STT_MODEL=whisper-large-v3                          # للسحابي؛ يُحذف للمحلي
STT_API_KEY=<مفتاح الخدمة — سر>                    # يُرسل Bearer (للسحابي)
STT_TIMEOUT_SECONDS=60
STT_MAX_AUDIO_BYTES=26214400                       # 25MiB
```

> ملاحظة (نمط R-736): سير النشر لا يمرر هذه المتغيرات — تُضبط مباشرة
> `fly secrets set -a sovereign-ai-k20elq ...` ثم أمر نشر (المادة ١٠).
> والتحقق الحي بعده: `/stt/status` ثم ملف صوتي فعلي عبر `/stt`.
