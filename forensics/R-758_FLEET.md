# R-758 — أسطول الوكلاء (ROADMAP_V5 ٥.١ + ٥.٢ + ٥.٣)

> بأمر المالك 2026-10-25: «أسلمك المشروع ابدء ولا تتوقف إلى بعد تحقيق الهدف».

## ما بُني
- `backend/fleet.py`:
  - **٥.١ `Worker`:** حلقة R-753 بدور واحد وهدف جزئي وميزانية خطوات خاصة و`CancelToken`؛ أثر `fleet_event` (`worker.spawn` / `worker.stop` / `worker.result`)؛ تعذر أثر الإنشاء = لا تشغيل (`ledger_blocked`)؛ الإيقاف نافذ دائمًا.
  - **٥.٢ `FleetCoordinator`:** `ThreadPoolExecutor` بسقف تزامن؛ انهيار عامل يُعزل (`crashed`) ولا يمس غيره؛ إعادة جدولة الفاشل حتى `max_retries` (لا إعادة لـ`ledger_blocked`/`cancelled`)؛ تقرير: `registered` / `runnable_concurrency_cap` / `measured_peak_concurrency` / `completed` / `failed[]` / `retried{}` / `status` (`completed`/`partial`/`failed`/`blocked`).
  - **٥.٣ `measure_scale`:** تشغيل فعلي؛ الذروة من عداد حي داخل التنفيذ؛ RSS بعينات `/proc/self/status` كل 20ms.
- أداة `fleet.spawn` (عمال بالعقل الحي، سقف `FLEET_MAX_CONCURRENCY` افتراضي 8 — مناسب لآلة 512MB حتى يُقاس هناك).
- `tools/fleet_scale_report.py` → `forensics/R-758_SCALE_REPORT.json`.
