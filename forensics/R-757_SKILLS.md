# R-757 — اكتساب المهارات (ROADMAP_V5 ٤.٢ + ٤.٣)

> بأمر المالك 2026-10-25: «أسلمك المشروع ابدء ولا تتوقف إلى بعد تحقيق الهدف».

## ما بُني
- `backend/skills.py`:
  - **الحزمة:** `name/version/source/description/inputs/permissions/steps/output/eval` — بصمة محتوى SHA-256.
  - **الدورة:** `propose` (proposed) → `evaluate` (كل حالة مرجعية تُشغل وتُقارن؛ نجاح الكل = evaluated وإلا failed_eval) → `approve` (المالك فقط؛ يشترط evaluated وتطابق البصمة الحالية مع المقيمة؛ الأثر `skill_lifecycle` أولًا وفشله = لا تفعيل) → أداة `skill.<اسم>` → `rollback` للإصدار السابق.
  - **التنفيذ:** الخطوات قوالب فوق أدوات مسجلة تُنفذ عبر حلقة R-753؛ أداة خارج أذونات الحزمة → `invalid_step`.
  - **الدوام:** `load_active` عند الإقلاع يسجل المفعّل من القرص (`data/skills/`) — لا إعادة تعلم.
  - **٤.٣:** `skills.status` يعلن أدوات `mcp.*` المكتشفة `learned=false` حتى تدرجها حزمة مفعّلة.
- `backend/tool_registry.py`: `replace` — استبدال مقصود (تفعيل إصدار/تراجع)؛ `register` يبقى رافضًا للتكرار.
- `backend/app.py`: `POST /skills/approve` و`/skills/rollback` (مفتاح المالك)، أدوات `skills.install`/`skills.status`، التحميل عند الإقلاع.
