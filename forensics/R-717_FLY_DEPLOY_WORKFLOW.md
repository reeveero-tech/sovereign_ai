# R-717 — النشر على Fly.io عبر GitHub Actions (بأمر المالك — 2026-10-22)

**الأساس:** `eda936a` (R-716). **الأمر:** المالك وفّر رمز Fly وأمر بالنشر («أنشر فعلًا»، «انشر انت وتول كل شي انت»)، واختار طريق GitHub Actions.

## ١) ما نُفّذ على Fly قبل هذا الالتزام (من بيئة الوكيل، عبر نقل آمن للرمز)

- قراءة: التطبيق `sovereign-ai-k20elq` (منظمة `ader-goool`) حالته `suspended`؛ جهاز واحد `stopped` بفحص صحي 0/1؛ **صفر أسرار** — يطابق الرفض المغلق (D-034/R-602): نشر سابق بلا `SOVEREIGN_KEY` يرفض الإقلاع.
- `fly secrets set --stage`: `SOVEREIGN_KEY` (مولَّد بـ `secrets.token_urlsafe(48)`، لم يُطبع في أي سجل؛ نسخة سُلّمت للمالك) و`CORS_ORIGINS=https://sovereign-ai-k20elq.fly.dev`. الحالة: Staged.
- محاولة `flyctl deploy --remote-only --depot=true`: فشلت `error building: unavailable: Forbidden`. سجل debug: الطلبات إلى `api.fly.io` و`api.machines.dev` نجحت؛ اتصال البنّاء (Depot — gRPC، أو WireGuard للبنّاء الكلاسيكي) ليس HTTPS فلا تسمح به بيئة الوكيل. لم يُحاوَل أي التفاف.
