# DOMAIN.md — منطق العمل (Domain)

> ما منطق العمل؟ وصف صادق لما يفترض أن يفعله النظام.
> آخر تحديث: 2026-10-12 (الدفعة M3)

---

## 1) المفهوم

**SOVRA** نظام "ذكاء سيادي" تجريبي. الفكرة المركزية:

> عقل اصطناعي **يتعلم** و**يتطور** ذاتياً، لكنه **لا يعدّل نفسه** إلا بعد **إذن السيد** (المالك).

المصطلحات الأساسية:
- **السيد (Master)**: المالك — السلطة العليا. يملك مفتاح API ورمز إعادة التفعيل.
- **الذكاء السيادي (Sovereign Intelligence)**: النظام نفسه — "يخدم السيد بإخلاص".
- **الدورة (Cycle)**: وحدة المعالجة — إدراك → قرار → تنفيذ → تحديث ذاكرة.
- **السيادة (Sovereignty)**: مبدأ أن النظام يملك "إرادة" لكنها مقيدة بإذن السيد.

---

## 2) دورة المعالجة (كما في orchestrator.py)

```
إدراك (Perception) → تقييم سيادي (Sovereign Eval) → تحليل مستقبل (Future Analysis)
→ قرار (Decision) → تنفيذ (Execution) → تحديث ذاكرة (Memory Update)
```

القرارات الممكنة (rule-based):
- `monitor` — مراقبة (خطر متوسط).
- `continue` — متابعة (خطر منخفض).
- `explore` — استكشاف (فرصة عالية).
- `activate_defense` — تفعيل دفاع (خطر مرتفع).
- `noop` — لا عملية.

---

## 3) طبقة "السيادة" (safety.py)

أنواع الأفعال التي تتطلب موافقة السيد:
- `SELF_MODIFY` — تعديل ذاتي.
- `DELETE_MEMORY` — حذف ذاكرة.
- `RUN_EXPERIMENT` — تشغيل تجربة.
- `ACCESS_PRIVATE` — وصول خاص.
- `EXTERNAL_UPLOAD` — رفع خارجي.
- `LEARN_TOPIC` — تعلم موضوع.
- `SHUTDOWN` — إيقاف.

---

## 4) الحقيقة الصادقة (مهم) — قرار D-010 (R-302)

> **القرار (D-010)**: إعادة التوصيف بصدق — لا يُضاف نموذج لغوي حقيقي الآن. النظام **نظام قرارات قائم على قواعد (rule-based)**، وليس "ذكاءً" بالمعنى التقليدي. إضافة نموذج حقيقي قرار مستقبلي للسيد (يتطلب اعتماديات ثقيلة).

- القرارات حالياً **قواعد بسيطة** (تحليل مخاطر/فرص)، ليست ذكاءً حقيقياً.
- لا يوجد نموذج لغوي فعلي (رغم تعريف `CORE_MODEL_NAME` = `microsoft/Phi-3-mini-4k-instruct` — غير مثبت ولا يُستورد).
- "الوعي" و"الكم" و"الإرادة" هي **محاكاة مفاهيمية** داخل فئات Python.
- النظام **لا يعدّل نفسه فعلياً** — لا يوجد آلية تعديل ذاتي حقيقية (راجع OPEN_QUESTIONS س-9).
- **التوصيف الصادق**: SOVRA هو **إطار تجريبي لمحاكاة سيادة معرفية** — يدرك، يقرر بقواعد، يطلب إذن السيد. ليس نموذجاً لغوياً.
