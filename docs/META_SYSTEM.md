## القواعد الموروثة (ملزمة لكل جولة لاحقة)

- **القاعدة الأم:** لا تثق بادعاء غير مُتحقق منه — تحقّق، ثم أنجِز، ثم أثبِت.
- **RED أولًا** لأي عمل كود: اختبار يفشل فعلًا، يُشاهد فشله، ثم يُصلح (استُثنيت منه الجولات التوثيقية الصرفة بقرار المالك).
- **الالتزام الذري:** كود + اختبار + توثيق + مدخل حذف (إن وُجد) + PROJECT_STATE + CHANGELOG في نفس الالتزام.
- **الدورة الكاملة:** push ← انتظار CI فعليًا ← `verify.sh --full` من clone نظيف ← تطابق ثلاثي ← توقيع.
- **التاريخ لا يُمحى:** لا force-push ولا amend ولا rebase على main. أي حذف (ملفًا أو سطرًا) يستلزم `# DELETION-JUSTIFIED` في رسالة الالتزام + مدخلًا في `forensics/DELETED_LINES_AUDIT.md`.
- **القرارات المعمارية الكبرى والإعلانات الخارجية والنشر:** للمالك وحده.
