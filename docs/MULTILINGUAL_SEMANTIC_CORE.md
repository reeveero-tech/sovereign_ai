## ١. المبدأ الحاكم

الفهم الأصيل أولًا: النص الأصلي يُحلَّل بخصائص لغته مباشرة (مورفولوجيا عربية،
تركيب إنجليزي، تبديل شيفرة) — **لا يمر النص بأي مترجم وسيط**. اللغة واجهة والتمثيل
الدلالي (مفاتيح المفاهيم `concept_key`) هو الأساس. البرهان: كل إطار تحليل يحمل
`"analysis_path": "original_text"`، والاختبار `test_no_intermediate_translation`
يُثبت غياب أي نداء ترجمة في المسار (لا استيراد لوحدات الترجمة في الحزمة إطلاقًا).

## ٢. المعمارية — مخطط تدفق البيانات

```
رسالة المستخدم (أي لغة / مختلطة)
      │
      ▼
┌─────────────────────── detector.py ───────────────────────────┐
│ كشف اللغة على مستوى المقطع + تقسيم تبديل الشيفرة              │
│ (تشغيل كلمة داخلية مختلطة: «الـPR» ⇒ الـ + PR)                │
└────────────────────────────┬──────────────────────────────────┘
                             ▼
┌─────────────────────── frame.py ──────────────────────────────┐
│ المحلل الدلالي: نية/فعل كلام/كيانات/مراجع/علاقات خطابية/غموض   │
│ عقد JSON إلزامي (٤.٢) — تحليل صرفي حتمي من النص الأصلي         │
└───────┬─────────────────┬─────────────────┬───────────────────┘
        ▼                 ▼                 ▼
┌──────────────┐ ┌──────────────┐ ┌────────────────────────────┐
│ entity_table │ │  memory.py   │ │ (لاحقًا في الدورة)          │
│ جدول الكيانات│ │ هرمية: عمل/  │ │ حل الإحالات + استرجاع      │
│ + حل الإحالات│ │ حلقي/دلالي   │ │ عبر اللغات + سياق مجمع      │
└──────────────┘ └──────────────┘ └────────────────────────────┘
        │                 │
        └────────┬────────┘
                 ▼
┌────────────────────── pipeline.py ────────────────────────────┐
│ دورة الوكيل الواحدة: تحليل ⇒ تحديث الجدول/الذاكرة ⇒ حل الإحالات│
│ ⇒ استرجاع ⇒ سياق ⇒ سؤال قائم بذاته ⇒ (توليد خارج الحزمة)      │
│ ⇒ validate_reply (مدقق بعد التوليد)                            │
└──────────────────────────────────────────────────────────────┘
```

الربط بـ`app.py` (نقطة `/chat`): `multilingual.resolve(text, history)` مسار أولي
(يحل الإحالات ويعيد `standalone` يغذي العقل والبحث)، و`context_resolver` القديم
احتياط متوافق، ثم `multilingual.validate_reply` قبل إرسال الرد (قاعدة: لا يخرج
رد فيه ضمير غير مربوط أو كيان غير مثبت).

## ٣. الوحدات

| الوحدة | المسؤولية |
|---|---|
| `scripts.py` | نطاقات يونيكود، تقطيع، تطبيع للمطابقة فقط (لا يُعرض أبدًا) |
| `detector.py` | كشف لغة المقطع + تبديل الشيفرة داخل الجملة والكلمة |
| `lexicon.py` | مفاهيم متعددة اللغات (`COUNTRY:JAPAN` = اليابان/Japan) — أساس الربط عبر اللغات |
| `frame.py` | المحلل الدلالي + عقد JSON + مورفولوجيا عربية (ال التعريف، مثنى/جمع، ضمائر متصلة/منفصلة، حذف فاعل) |
| `entity_table.py` | جدول الكيانات + محرك حل الإحالات (البروز/الحداثة/النشاط + تعزيزات الأدوار) |
| `memory.py` | ذاكرة هرمية (عمل/حلقي/دلالي) + سياسة النسيان والتعارض (انظر سياسة الذاكرة) |
| `validator.py` | المدقق بعد التوليد: ضمائر غير مربوطة، كيانات غير مثبتة، اتساق اللغة |
| `pipeline.py` | حلقة الوكيل الواحدة + واجهة `resolve()` المتوافقة عكسيًا مع `context_resolver` |

## ٥. مواصفة محرك حل الإحالات (Coreference)

**المرشحون:** كيانات الجدول الحية المستبعد منها مسندات المعجم (`PROP:`/`ACT:`)
والصفات الشائعة. **التقييم:**

```
score = 0.45×salience + 0.35×recency + 0.20×active
+ 0.5 إن كان الضمير مفعولًا لحرف جر/فعل («عليه/وصلتها»)
+ 0.4 إن كان فاعلًا محذوفًا (استرجاع الفاعل)
+ 2.0 تطابق سطح اسم معرّف («الكيان نفسه»)
```

- **الغموض المؤثر:** إذا اقترب أفضل مرشحَين (هامش < 0.15) ⇒ `ambiguous: true`
  و`clarification` بسؤال توضيح **واحد** — لا تخطئة صامتة.
- **الضمائر العربية:** المنفصلة (هو/هي/هم/هن/هما) والمتصلة (ها/ه/هم/ك/نا…)،
  والمتصلة بالفعل («وصلتها») تُعلَّم `attached_to: "verb"` فلا يُبتر الفعل أبدًا.
- **حذف الفاعل (pro-drop):** فعل مصروف بلا فاعل صريح ⇒ مرجع `[فاعل محذوف: فعل]`
  يُسترجع من الجدول (تسكين رول الفاعل). مرور لاحق يزيل الحذف الزائف إن وُجد
  فاعل صريح (VSO: أول اسم بعد الفعل فاعل).
- **التعريف والعدد:** «ال» تميز الكيان المعروف؛ المثنى (ـان/ـين، أفعال بلاحقة ا)
  والجمع مميزان في الخصائص ويؤثران في المطابقة.
- **الأسماء عبر اللغات:** «Japan» و«اليابان» كيان واحد (`concept_key` مشترك)
  عبر أسطح متعددة باللغة.

## ٦. قواعد السؤال القائم بذاته (standalone)

| الحالة | القاعدة | مثال |
|---|---|---|
| ضمير منفصل/إشارة | استبدال بالاسم | «هي تعجبني» ⇒ «اليابان تعجبني» |
| اسم + ضمير متصل | جذر + اسم الكيان | «سكانها» ⇒ «سكان اليابان» |
| فعل + ضمير مفعول (و«ني») | لا بتر — سياق بالنهاية | «تعجبني» ⇒ يبقى + «— المقصود: اليابان؟» |
| حذف فاعل | إدراج الفاعل المسترجع | «زرتها» ⇒ «زرت اليابان» |
| لا إحالات | النص كما هو | — |

قاعدة الصدق: لا جراحة نصية خطرة — التعويض المكسور يُستبدل بسياق آمن.

## ٧. الإثباتات

- **بلا ترجمة وسيطة:** `analysis_path: "original_text"` في كل إطار +
  اختبار سلوكي `test_no_intermediate_translation` + صفر استيراد لوحدات الترجمة
  في الحزمة (فحص استاتيكي بالاختبار).
- **الاسترجاع عبر اللغات:** سؤال إنجليزي يسترجع وحدة معنى خُزنت بالعربية عبر
  مفتاح المفهوم (`COUNTRY:JAPAN` + `PROP:CAPITAL`) — درجة تطابق 1.0.
- **الخصوصية:** أثر التحليل (`trace`) يحمل لغات وأكواد مشكلات فقط — لا نص
  مستخدم في السجلات (اختبار `test_privacy_no_leak_in_trace`).
