# RISKS.md — سجل المخاطر

> كل خطر مُتحقق منه أو محتمل، مع شدته وتأثيره وخطة المعالجة.
> آخر تحديث: 2026-10-12 (الدفعة M0)

---

## 1) مقياس الشدة

- 🔴 **حرج** — خطر أمني/فقدان بيانات/منع بناء.
- 🟠 **مرتفع** — خطر تشغيلي/أمني كبير.
- 🟡 **متوسط** — خطر تشغيلي.
- 🟢 **منخفض** — خطر بسيط.
