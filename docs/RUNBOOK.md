# دليل التشغيل والتراجع (R-838)

> **التاريخ:** 2026-11-02 · **المكون:** النواة الدلالية متعددة اللغات
> (`backend/multilingual/` + تكامل `/chat`)

## ١. التشغيل العادي

- لا شيء جديد يُشغل: الحزمة stdlib خالص بلا إعدادات ولا مفاتيح ولا شبكة.
- مراقبة السجلات (grep):
  - `R-838: تعذر المسار الدلالي` ⇒ سقوط للاحتياط (توقع نادر؛ تكراره عيب يُفتح).
  - `R-838: المدقق البعدي رصد` ⇒ الضمائر/الكيانات المرصودة في رد — مراجعة نوعية.
  - `R-838: تعذر التحقق البعدي` ⇒ المدقق سقط (TOLERATED — الرد خرج سليمًا
    من مساره الآخر).

## ٢. اختبار صحة سريع بعد النشر

```bash
curl -s $BASE/chat -H 'content-type: application/json' -d '{
  "text": "هي تعجبني",
  "history": [{"role":"user","content":"اليابان بلد جميل وسكانها مهذبون."},
              {"role":"assistant","content":"رائع!"}]
}' | python3 -c "import sys,json; print(json.load(sys.stdin)['resolved_question'])"
# المتوقع: «اليابان تعجبني» — الضمير حُل من جدول الكيانات
```

## ٣. حالات الفشل المعروفة

| العرض | السبب | الإجراء |
|---|---|---|
| `resolved_question` = النص الخام | سقط المسار الدلالي (سجل R-838) | تفتيش الاستثناء في السجل؛ الرد صحيح لكن بلا حل ضمائر |
| توضيح مكرر في الرد | المدقق ألحق سؤالًا | مقبول (أمان) — يُحلن كتحسين |
| لغة الرد لا تطابق | كشف لغة حدّي | يُرصد بنوعية لا كحالة حرجة |

## ٤. التراجع (Rollback)

**تراجع بلا إعادة نشر** (أسرع، لأعراض سلوكية):

```python
# في /chat: تقديم المسار القديم — عكس شرط الاستدعاء أو حذف كتلة
# «النواة الدلالية» (كائنة بـ«R-838 (المعمارية متعددة اللغات)» أعلى الدالة)
# يكفي إبطال متغير الحارس:
```

1. فتح `backend/app.py` عند علامة `R-838 (المعمارية متعددة اللغات)`.
2. تعليق استدعاء `multilingual.resolve(...)` وترك `context_resolver.resolve(...)`
   (السطر التالي له مباشرة — الاحتياط الموجود أصلًا).
3. المدقق البعدي مستقل — يمكن إبقاؤه (آمن) أو تعطيله بتعليق كتلة
   `المدقق بعد التوليد`.

**تراجع بإعادة نشر** (لخلل في الحزمة نفسها):

```bash
git revert <SHA-R-838> && git push origin work/r-838-multilingual-core
# ثم PR عكسي — أو مباشرة:
git push https://github.com/reeveero-tech/sovereign_ai.git <sha>:main
```

بوابة الحذف تتطلب `# DELETION-JUSTIFIED` في رسالة أي التزام تراجع يحذف أسطرًا.
