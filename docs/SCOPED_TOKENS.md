## التصميم

| المكوّن | الدور |
|---|---|
| `backend/scoped_tokens.py` | `TokenManager`: إصدار/فحص/إبطال/سرد/استعلام. الرمز `sct1.<مطالبات base64url>.<HMAC-SHA256>` بمفتاح مشتق لغرض `scoped_tokens` (HKDF من جذر المالك، منفصل عن `api_auth`) |
| `authorize(key, scope)` في `backend/app.py` | المفتاح الرئيسي يمر بكل نطاق؛ الرمز بنطاقه فقط؛ أي خطأ في الفحص = رفض |
| إبطال دائم | قائمة jti محلية + كتابة نافذة للمخزن الدائم (SupabaseDisk، namespace `auth_tokens`). عند الإقلاع تُحمّل القائمة؛ إن كان المخزن مضبوطًا وتعذر التحميل ⇒ **كل الرموز مرفوضة** حتى ينجح (إعادة محاولة كل 30 ثانية) — لا يعود رمز مبطل حيًا بعد إعادة نشر |
| السجل السيادي | `auth.token_issued` و`auth.token_revoked` بـ jti والنطاقات فقط. سجل لا يوقّع ⇒ لا رمز (503) |
| `secret_guard` | قاعدة `sovereign_scoped_token` (حرجة): أي رمز يتسرب في سجل أو رد يُخفى، وبوابة المستودع تكشفه |
| `derivation.PURPOSES` | غرض جديد `scoped_tokens` — تسريب مفتاح التوقيع لا يكشف مفتاح المصادقة |

## الاستعمال

```bash
# إصدار رمز قراءة لمدة يوم (يُعرض مرة واحدة — احفظه)
curl -X POST $URL/auth/tokens -H 'Content-Type: application/json' \
  -d '{"api_key":"<المفتاح الرئيسي>","scopes":["read"],"ttl_seconds":86400,"label":"phone"}'
# ما يملكه الرمز
curl $URL/auth/whoami -H 'X-Sovereign-Key: <الرمز>'
# سرد الرموز (بيانات وصفية بلا أسرار)
curl $URL/auth/tokens -H 'X-Sovereign-Key: <المفتاح الرئيسي>'
# إبطال فوري
curl -X POST $URL/auth/tokens/revoke -H 'Content-Type: application/json' \
  -d '{"api_key":"<المفتاح الرئيسي>","jti":"<معرّف الرمز>"}'
# النطاقات والحالة (عام، بلا أسرار)
curl $URL/auth/status
```

الرمز يوضع حيث كان المفتاح يوضع: الرأس `X-Sovereign-Key` أو `X-API-Key` أو الحقل `api_key`.

## التحقق

- مجموعة مجمّدة `auth.scoped_tokens` (20 حالة، أرضية 1.0) في بوابة CI: النطاق، الانتهاء، الإبطال، كشف التلاعب والمفتاح الأجنبي، عدم تفويض الإدارة، حدود العمر، المدخلات المشوهة، دوام الإبطال عبر إعادة النشر، الرفض حين تتعذر قائمة الإبطال، فشل السجل، عدم تخزين السر، كشفه في كتالوج الأسرار.
- `tests/test_r851_scoped_tokens.py` (10): الربط بالنقاط الحية — رمز `read` يقرأ ولا يكتب ولا ينفذ، رمز بكل النطاقات لا يصدر رمزًا ولا يعيد الضبط، الإبطال فوري.

## الحدود (معلنة)

- المفتاح الجذري القديم ما زال مقبولًا لكل العمليات كالمفتاح الرئيسي — توافقًا مع ما يستعمله المالك؛ تقييده قرار للمالك لاحقًا (يُعلن في `/auth/status`).
- نطاق `tools` يفتح كل الأدوات المسجلة؛ تقسيمه لكل أداة توسعة لاحقة.
- تدوير جذر المالك يبطل كل الرموز دفعة واحدة (مفتاح التوقيع مشتق منه) — وهذا مقصود.
