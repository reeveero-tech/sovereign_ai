## 4) نمط الكود الموحد (R-203)

> اعتمد في M2. يُطبق على الكود الجديد والمعدَّل.

### Python
- **المسافات**: 4 مسافات، لا تبويب.
- **الاستيرادات**: مطلقة (absolute) — `from orchestrator import ...` لا `from .orchestrator`.
- **التوثيق**: docstring عربي/إنجليزي لكل دالة/فئة (نمط `"""..."""`).
- **طول السطر**: ≤ 100 حرف (23 سطراً حالياً تتجاوز — تُعالج تدريجياً).
- **معالجة الأخطاء**: `try/except` مع `logger.error` — لا `pass` صامت.
- **التسمية**: `snake_case` للدوال والمتغيرات، `PascalCase` للفئات، `UPPER_CASE` للثوابت.

### JavaScript
- **المسافات**: 4 مسافات.
- **المفاتيح**: مقتبسة عند الحاجة (لا واصلات غير مقتبسة — خطأ R-102).
- **التسمية**: `camelCase` للدوال والمتغيرات، `PascalCase` للفئات.

### عام
